# Contributing to p12-rust

Thank you for your interest in contributing to the p12-rust learning project! This guide will help you make contributions.

## How to Contribute

### Reporting Issues

If you find any problems with the projects or documentation:

1. Check if the issue already exists
2. Create a new issue with:
   - Clear description of the problem
   - Steps to reproduce (if applicable)
   - Expected vs actual behavior
   - Your environment (OS, Rust version)

### Suggesting Improvements

Have ideas for better projects or improvements?

1. Open an issue describing your suggestion
2. Explain why it would be beneficial
3. Wait for feedback before starting work

### Contributing Code

#### Project Improvements

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/improvement-name`
3. Make your changes
4. Test your changes
5. Commit with clear messages
6. Push to your fork
7. Open a Pull Request

#### Code Style

- Follow [Rust style guidelines](https://doc.rust-lang.org/1.0.0/style/)
- Run `cargo fmt` before committing
- Run `cargo clippy` and fix warnings
- Write clear, self-documenting code
- Add comments for complex logic

#### Commit Messages

Use clear, descriptive commit messages:
```
Add solution for Month 3 Todo List

- Implemented basic CRUD operations
- Added JSON persistence
- Created unit tests
```

### Documentation Contributions

Documentation is crucial for learners!

- Fix typos or unclear explanations
- Add missing examples
- Improve learning objectives
- Enhance getting started guides
- Share learning tips

### Adding New Projects

To propose a new monthly project:

1. Ensure it fits the learning progression
2. Create a detailed README with:
   - Learning objectives
   - Technical concepts
   - Implementation exercises
   - Resources
3. Test the project yourself
4. Submit as Pull Request

## Code Review Process

1. Maintainers will review your PR
2. Address any requested changes
3. Once approved, PR will be merged
4. Your contribution will be acknowledged

## Community Guidelines

- Be respectful and constructive
- Help fellow learners
- Share knowledge and experiences
- Ask questions when unclear
- Celebrate progress and achievements

## Questions?

Open an issue or reach out through:
- GitHub Discussions
- Issue comments

Thank you for contributing to help others learn Rust! 🦀
