# p12-rust

A project for learning Rust programming language fundamentals by building 12 small applications over one year - one project per month. This repository serves as a structured learning path to strengthen Rust programming skills through practical, hands-on projects.

## 📚 Project Overview

This repository contains 12 monthly projects designed to progressively teach Rust concepts from beginner to intermediate level. Each project focuses on specific Rust features and best practices.

## 🗓️ 12-Month Project Roadmap

### Month 1: Hello CLI - Command Line Interface Basics
**Concepts**: Basic syntax, variables, functions, string manipulation, user input  
**Project**: Build a simple command-line calculator or greeting program

### Month 2: Guessing Game
**Concepts**: Random numbers, loops, error handling, match expressions  
**Project**: Create an interactive number guessing game

### Month 3: Todo List CLI
**Concepts**: Vectors, structs, file I/O, JSON serialization  
**Project**: Build a command-line todo list application with persistence

### Month 4: File Organizer
**Concepts**: File system operations, path handling, pattern matching  
**Project**: Develop a utility to organize files by type/date

### Month 5: Web Scraper
**Concepts**: HTTP requests, HTML parsing, error handling, async/await  
**Project**: Create a web scraper to extract data from websites

### Month 6: REST API Client
**Concepts**: HTTP clients, JSON parsing, API integration, error propagation  
**Project**: Build a CLI tool that interacts with a public REST API

### Month 7: Markdown Parser
**Concepts**: String parsing, enums, pattern matching, recursion  
**Project**: Implement a basic Markdown to HTML converter

### Month 8: Chat Server
**Concepts**: TCP networking, threading, channels, concurrent programming  
**Project**: Create a multi-client chat server

### Month 9: Database Manager
**Concepts**: SQL integration, CRUD operations, connection pooling  
**Project**: Build a CLI database management tool

### Month 10: Web Server
**Concepts**: HTTP server, routing, middleware, web frameworks  
**Project**: Develop a simple web server with REST endpoints

### Month 11: System Monitor
**Concepts**: System APIs, data visualization, real-time updates  
**Project**: Create a system resource monitoring tool

### Month 12: Final Project - Mini Application
**Concepts**: Integration of all learned concepts  
**Project**: Build a complete application combining multiple concepts

## 🚀 Getting Started

### Prerequisites
- Install Rust: https://rustup.rs/
- Verify installation: `rustc --version`
- Familiarize with Cargo: `cargo --help`

### Running a Project
```bash
cd month-XX-project-name
cargo build
cargo run
cargo test
```

### Learning Path
1. Start with Month 1 and work through each project sequentially
2. Read the project-specific README for learning objectives
3. Attempt to implement features before looking at solutions
4. Experiment and modify the code to deepen understanding
5. Complete the exercises and challenges in each project

## 🎯 Learning Objectives

By completing all 12 projects, you will:
- ✅ Master Rust syntax and core concepts
- ✅ Understand ownership, borrowing, and lifetimes
- ✅ Work with common data structures and algorithms
- ✅ Handle errors gracefully using Result and Option
- ✅ Build concurrent and parallel programs
- ✅ Create network applications
- ✅ Work with external APIs and libraries
- ✅ Write idiomatic Rust code
- ✅ Test and debug Rust applications
- ✅ Build complete, real-world applications
